# بوت أسعار الذهب

بوت تيليقرام يعطي سعر جرام الذهب بالريال السعودي لكل العيارات — بأسعار مباشرة من السوق.

## المعادلة

```
سعر الجرام = سعر الأونصة($) × سعر الصرف ÷ 31.1034768 × (العيار ÷ 24)
```

## بدون أوامر — اكتب عادي

البوت يفهم الكلام الطبيعي، فما أحد يحتاج يحفظ صيغ:

| تكتب | يفهم |
|---|---|
| `12 جرام عيار 21` | قيمة ١٢ جرام عيار ٢١ |
| `نص كيلو 24` | قيمة ٥٠٠ جرام عيار ٢٤ |
| `250 قرام` | قيمة ٢٥٠ جرام بعيارك المفضل |
| `كم سعر عيار 22` | سعر جرام عيار ٢٢ + جدول الأوزان |
| `4380` | يحوّل سعر الأونصة لسعر الجرام |

يقبل «جرام / قرام / غرام / كجم / kg»، والأرقام العربية `١٢٫٥`، و«نص» و«ربع» كيلو.

## الأوامر

لوحة أزرار ثابتة: **السعر الآن • عياري • احسب وزن • السبائك • قارن محل • تنبيهاتي • مساعدة**.

## مصادر الأسعار

**كل مصادر الذهب سوق فوري (spot) يقفل نهاية الأسبوع** — بدون عقود آجلة ولا توكنات كريبتو.

| البيانات | المصادر بالترتيب | التحديث |
|---|---|---|
| سعر الذهب | Swissquote ← gold-api ← fxratesapi | **مع كل طلب، بدون تخزين** |
| إغلاقات يومية | fxratesapi timeseries | ساعة |
| سعر الصرف | exchangerate-api ← currency-api | 6 ساعات |

كلها مجانية وبدون مفتاح API. إذا فشل مصدر ينتقل للي بعده، وإذا فشل الكل يرجّع آخر قيمة
معروفة **ويعلّمها «قديمة»** بتحذير واضح.

### ليش هذي المصادر بالذات

قِسنا البدائل على نفس اللحظة، والفروق كانت جوهرية:

| المصدر | السعر | الفرق | الحكم |
|---|---|---|---|
| gold-api | $4,377.60 | مرجع | ✅ فوري |
| Swissquote | $4,376.19 | −0.03% | ✅ فوري + وقت تسعيرة حقيقي |
| fxratesapi | $4,375.60 | −0.05% | ✅ فوري + إغلاقات تاريخية |
| Yahoo `GC=F` | $4,437.30 | **+1.36%** | ❌ عقود آجلة — ٦ ريالات فرق على الجرام |
| PAXG (كريبتو) | $4,377.00 | −0.01% | ❌ يتداول ٢٤/٧، ما يقفل الويكند |

**Swissquote أولاً** لأنه بنك سويسري يعطي `bid`/`ask` **ومعها وقت التسعيرة الحقيقي**.
باقي المصادر تختم وقت سحبها هي للبيانات — يوم السبت تقول «السعر عمره ٤ دقائق» وهو
عمره ٢١ ساعة. لذلك نرجّع `None` لطوابعها بدل ما نوهم بطزاجة.

### الحماية من البيانات الخاطئة

- **حدود منطقية:** ١٠٠–١٠٠٬٠٠٠ دولار للأونصة
- **فحص القفزات:** أي سعر يبعد أكثر من **٣٪** عن آخر قيمة خلال نصف ساعة يُرفض ويُجرَّب
  المصدر التالي — يكشف مصدراً بدأ يرجّع بيانات خربانة. وبعد نصف ساعة صمت نسمح بالفجوة
  لأن فجوة الافتتاح مشروعة.
- **مهلة ٢٫٥ ثانية لكل مصدر:** قِسنا قفزة ٥٫٤ ثانية من أحد المصادر، والانتقال للتالي
  أسرع من الانتظار.

### التغيّر اليومي

يُحسب من إغلاقات **نفس السوق الفوري** (`fxratesapi timeseries`)، مو من العقود الآجلة.
وقت التداول يقارن بإغلاق أمس؛ وإذا كان السوق مغلقاً يرجع خطوة إضافية عشان تظهر حركة
آخر يوم تداول بدل صفر.

## طزاجة السعر

**سعر الذهب لا يُخزَّن** — كل رسالة تجلب من السوق. زمن الطلب قِيس بـ~305ms.

حمايتان من الإغراق، وكلاهما ليس تخزيناً:

- **مشاركة الطلب الجاري:** عشر رسائل في نفس اللحظة = طلب واحد، والعشرة يأخذون نتيجته.
- **أرضية ثانيتين** (`MIN_REFETCH_SECONDS`): مستخدم يرسل ٥٠ رسالة متتالية كان سيطلق
  ٥٠ طلباً. المصدر نفسه يحدّث كل بضع دقائق، فسعر عمره ثانيتان هو **نفس** ما سيرجّعه
  طلب جديد. اضبطها على `0` لتعطيلها تماماً.

القيمة الموسومة «قديمة» لا تُعاد عبر الأرضية أبداً — تُجرَّب المصادر من جديد.

## ضريبة القيمة المضافة

`/shop` يفكك سعر المحل بدل ما يكوّم كل الفرق في خانة «مصنعية»:

```
سعر المحل:        600.00
− ضريبة 15%:       78.26
= قبل الضريبة:    521.74
− ذهب خام:        461.81
= المصنعية:        59.93 ريال (12.98%)
```

الضريبة مفروضة على **إجمالي** البيع (ذهب + مصنعية) وهي داخلة في السعر المعروض،
فتُستخرج بالقسمة على ١٫١٥ لا بضرب سعر الذهب في ٠٫١٥.

الذهب الاستثماري (نقاء ٩٩٪+ وقابل للتداول عالمياً) معفى — أضف كلمة «سبيكة».
وعيار ٢٤ وحده يبلغ هذا النقاء، فالبوت يرفض إعفاء سبيكة عيار ٢١ ويشرح السبب.

## قياس المصادر تحت التداول

`measure_sources.py` ينتظر افتتاح السوق بنفسه ثم يسجّل المصادر كل ١٥ ثانية،
ويطلع تقريراً: الموثوقية، السرعة، كم يتحرك السعر، هل المصادر متفقة، وهل حدود
البوت (رفض القفزة ٣٪، وحد «السوق مغلق» ٢٠ دقيقة) مضبوطة.

```bash
.venv/bin/python measure_sources.py              # ينتظر الفتح ثم يسجّل ساعة
.venv/bin/python measure_sources.py --now        # ابدأ فوراً
.venv/bin/python measure_sources.py --report source_measurements.csv
```

سعر الصرف وحده مخزَّن ٦ ساعات عن قصد — الريال مربوط والمصدر يحدّث يومياً، فجلبه مع كل
رسالة يضاعف الطلبات بلا فائدة.

## حالة السوق

تُستنتج من **الطابع الزمني للتسعيرة** لا من ساعة مبرمجة: إذا كانت تسعيرة Swissquote أقدم
من ٢٠ دقيقة فالسوق واقف فعلاً. هذا يحمي من التوقيت الصيفي والعطلات الرسمية اللي ما
يعرفها جدول مبرمج. والجدول التقريبي (الجمعة ٢١:٠٠ ← الأحد ٢٢:٠٠ UTC) يبقى احتياطياً
لما يكون المصدر النشط بلا طابع زمني.

## كم الأسعار «لحظية»؟

- **السعر ليس لحظياً بمعنى التداول.** البوت يجلب مع كل رسالة (~٣٠٥ms)، لكن المصدر نفسه
  يحدّث كل بضع دقائق — فالتأخير الكلي وقت التداول من ثانية إلى دقيقتين. ممتاز للشراء من
  المحل، غير مناسب للمضاربة.
- **نهاية الأسبوع السعر مُجمَّد.** سوق الذهب الفوري يقفل الجمعة ٢١:٠٠ UTC ويفتح الأحد ٢٢:٠٠ UTC.
  البوت يعرض `🔴 السوق مغلق — سعر إغلاق الجمعة` مع وقت الفتح القادم، بدل ما يوهمك إن الرقم حيّ.
- **طوابع أغلب المصادر غير موثوقة.** `gold-api` يقول «قبل ثوانٍ» والسعر عمره ٢١ ساعة.
  البوت يعرض وقت التسعيرة الحقيقي من Swissquote، ويقول «جُلب» بدل «تسعيرة» لما يكون
  المصدر النشط بلا طابع موثوق.

## الدقة

- كل الحسابات بـ `Decimal` بدقة 34 خانة — لا أخطاء الفاصلة العائمة (float).
- الأونصة التروية `31.1034768` جرام (التعريف الرسمي)، مو `31.1` المقرّبة.
- النقاء كسر دقيق `k/24` مو قيمة مقرّبة (عيار 22 = 0.91666… مو 0.9167).
- التقريب لخانتين يتم في **آخر خطوة فقط**، بعد كل الضرب والقسمة.
- الأرقام القادمة من الـ API تُحوَّل عبر `str` عشان ما نورّث خطأ `float`.
- يقبل الأرقام العربية `٣٤٠٠` والفاصلة العربية `٫` وفواصل الآلاف.

الأسعار للذهب الخام من مصادر عامة، للاسترشاد فقط — بدون مصنعية أو ضريبة أو هامش المحل.

## التشغيل

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
```

حط التوكن في ملف `.env` جنب `bot.py`:

```
BOT_TOKEN=123456:ABC...
```

ثم:

```bash
.venv/bin/python bot.py
```

التوكن من [@BotFather](https://t.me/BotFather). قائمة الأوامر ووصف البوت ينضبطون تلقائياً عند التشغيل.

انسخ `.env.example` إلى `.env` وعدّل القيم. `SITE_URL` اختياري — إذا حطيته يظهر زر
«دليل الاستخدام» داخل البوت، وإذا تركته فاضي يختفي الزر تلقائياً.

### تشغيل دائم (Linux)

ملف `gold-bot.service` جاهز لـ systemd مع إعادة تشغيل تلقائية:

```bash
sudo cp gold-bot.service /etc/systemd/system/ && sudo systemctl enable --now gold-bot
```

## صفحة الشرح (GitHub Pages)

`docs/index.html` صفحة عربية مكتفية بنفسها — بدون أي CDN أو خط خارجي (٤٤ كيلوبايت، ملف واحد).

**الواجهة:**
- سعر ضخم مباشر في الأعلى، يتغيّر بضغطة على أزرار العيار
- شريط علوي لاصق يظهر السعر عند التمرير
- شريط نقاء بصري لكل عيار، والضغط على أي صف ينسخ سعره
- شرائح أوزان جاهزة (١ · ٥ · ١٠ · ٥٠ · ١٠٠ · ٢٥٠ · ٥٠٠ · كيلو) + إدخال وزن حر
- زر وضع ليلي/نهاري محفوظ في المتصفح، وافتراضياً يتبع نظام الجهاز
- أرقام متحركة عند التحديث، وظهور تدريجي للأقسام عند التمرير
- مؤشر حالة السوق بنفس منطق `market.py`
- يحترم `prefers-reduced-motion` لمن يعطّل الحركة

الأسعار تُجلب من نفس مصادر البوت (تسمح بـ CORS)، وتتحدث تلقائياً كل دقيقتين.

لتشغيلها: **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / مجلد `/docs`**.

الرابط يصير `https://USERNAME.github.io/gold_bot/` — حطه في `.env` كـ `SITE_URL`.

اختبارات `test_docs.py` تتأكد أن ثوابت الصفحة (الأونصة، العيارات، الأوزان، مواعيد السوق)
مطابقة لملفات بايثون، فما تنحرف الصفحة عن البوت بالغلط.
